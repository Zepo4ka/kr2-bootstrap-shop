# Контрольная работа №2 — ShopProject

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Отдельная Bootstrap-реализация учебного магазина, не замена КР №1 или практической №8.

[Репозиторий](https://github.com/Zepo4ka/kr2-bootstrap-shop) · [Опубликованный сайт](https://zepo4ka.github.io/kr2-bootstrap-shop/)

## Четыре выбранные самостоятельные доработки

1. **Расширенный каталог** — `catalog.html` содержит шесть разных товаров вместо трёх базовых.
2. **Отдельная страница категории** — `category.html`, только аксессуары: рюкзак, бутылка и кепка; есть хлебные крошки и переходы к товарам.
3. **Блок отзывов** — `index.html#reviews`, три учебных примера отзывов в карточках.
4. **Блок часто задаваемых вопросов** — `index.html#faq`, Bootstrap Accordion с тремя раскрывающимися ответами.

Это четыре других пункта относительно защиты практической №8. Отзывы — примеры для учебной страницы, а не отзывы реальных покупателей.

## Обязательная Bootstrap-база

Использованы `container/row/col-*`, `navbar`, `card`, `btn`, `form-control`, `form-select`, `input-group`, `form-check`, `modal`, `alert`, `badge`. Они не считаются отдельными дополнительными пунктами.

Bootstrap 5.3.8 подключён через CDN с integrity; для загрузки библиотеки нужен интернет. Подключение соответствует [официальной документации Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/).

## Структура

- `index.html` — главная, популярные товары, отзывы, FAQ и Bootstrap-модалка;
- `catalog.html` — шесть карточек товаров;
- `category.html` — отдельная категория аксессуаров;
- `product.html` — товар, выбранный через параметр `product`, его характеристики и цена;
- `order.html` — форма заявки;
- `css/custom.css` — небольшие дополнения к Bootstrap;
- `js/products.js` — данные шести товаров;
- `js/main.js` — выбор товара, модалка и проверка форм;
- `images/` — SVG-изображения;
- `.gitignore` — исключения Git.

## Проверка и запуск

Откройте опубликованный сайт или `index.html`. Для локального сервера из папки проекта:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8766/`.

1. Откройте каталог и покажите шесть карточек.
2. Перейдите в «Аксессуары» — там только три товара этой категории.
3. На главной прокрутите до примеров отзывов.
4. В FAQ раскройте каждый ответ.
5. В каталоге нажмите «Подробнее», затем «Оставить заявку»: название и выбранный товар должны совпадать.
6. На главной кнопка «Заказать» открывает Bootstrap-модалку с выбранным товаром.
7. Проверьте пустую форму, неверный e-mail и телефон, согласие, сообщение об успешной проверке и сброс полей.
8. В узком окне проверьте раскрытие navbar и перенос карточек.

Товары и контакты учебные. Заявки проверяются в браузере, но не отправляются на backend и не сохраняются.
